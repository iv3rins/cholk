Cholk 的第一个公开版本。Cholk 是一个和 AI 角色聊天的 Android 和 Windows 应用。这个版本只提供 Android 安装包。

## 安装

1. 下载下面的 `cholk-v1.0.0.apk` 文件。
2. 在 Android 手机上打开这个文件。
3. 如果手机提示「禁止安装未知来源的应用」，请在系统设置里允许，然后再安装。

安装后，你需要连接一个模型才能聊天。你可以登录别人部署好的账号服务，也可以在「进阶模式」里填写你自己的 DeepSeek 或 OpenAI 兼容 API Key。详细步骤见仓库首页的 README。

## 这个版本包含的功能

- 和一个或多个 AI 角色聊天。每个角色有自己的名字、头像、性格和模型。
- 用 `@角色名` 让指定的角色回复。
- 新建、修改、导入和导出人格。人格以 JSON 文件保存，可以发给别人。
- 聊天模式适合日常对话。工作模式会让回复先给结论，并显示每个角色的生成进度。
- 普通模式只显示必要设置。进阶模式可以设置 API 协议、地址、模型和人格的工作流程。
- 聊天记录、人格、设置和 API Key 只保存在你的手机上。

## 已知限制

- 这个 APK 使用自动生成的测试签名。以后的版本可能使用不同的签名。如果新版本无法覆盖安装，请先卸载旧版本再安装。卸载会删除手机上的聊天记录。
- 记忆导出和远程 Agent 连接还没有实现。
- 这个版本没有 Windows 安装包。Windows 用户请按 README 从源代码构建。
