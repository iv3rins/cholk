Cholk 1.1.0 改进了手机上的输入和群聊体验。这个版本只提供 Android 安装包。

## 安装

1. 下载下面的 `cholk-v1.1.0.apk` 文件。
2. 这个 APK 和 1.0.0 一样使用自动生成的测试签名，签名可能不同，**请先卸载旧版本再安装**。卸载会删除手机上的聊天记录。
3. 在 Android 手机上打开这个文件。如果手机提示「禁止安装未知来源的应用」，请在系统设置里允许，然后再安装。

## 改进

- **键盘不再挡住输入框**：API 设置里的模型名、人格卡和成员的提示词、聊天输入框，在键盘弹出时会自动滚到键盘上方。
- **一键获取模型列表**：在 API 设置里填好地址和 Key 后，点「获取模型」即可从服务端拉取可用模型并选择，不用手动输入模型名。
- **群聊不再复述别人的话**：群聊中每个角色只把自己说过的话当作自己的发言，其他角色的发言会注明是谁说的，避免角色重复上一位的内容或给自己加名字前缀。
- **消息复制与选择**：在手机上长按一条消息，可以复制全文或进入选择页面选取部分文字。
- **自定义聊天背景**：在设置或聊天页顶栏的「聊天背景」里上传一张图片，可以调节遮罩深浅，也可以一键恢复默认。
- **首页字标可以拖动**：首页的 CHOLK 字母像挂在绳子上，可以用手指拖拽，在支持的设备上还可以打开倾斜感应。
- **免责声明**：首次打开时会显示免责声明，需要确认后才能使用；之后可以在设置里再次查看。

## 已知限制

- 这个 APK 使用 debug 测试签名，无法覆盖安装签名不同的旧版本。
- 键盘相关的改动只在模拟环境里测试过，还没有在所有机型上验证。如果仍然遇到键盘遮挡，请在 Issues 里告诉我们机型和系统版本。
- 记忆导出和远程 Agent 连接还没有实现。
- 这个版本没有 Windows 安装包。Windows 用户请按 README 从源代码构建。
